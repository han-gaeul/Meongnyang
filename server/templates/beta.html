멍냥동네 테스트 방법

아직 앱스토어에 없어서 조금 다른 방법으로 설치해요.
천천히 따라오면 5분이면 끝나요!

처음 한 번만 하면 돼요

  1. 'Expo Go' 앱 설치

    테스트 중인 앱을 열어 주는 무료 앱이에요. 멍냥동네는 이 앱 안에서 열려요.

    앱스토어에서 Expo Go 받기

  2. Expo Go에서 회원가입

    Expo Go를 열고 Sign up을 눌러 이메일로 가입해요.

    가입한 이메일 주소를 가을에게 카톡으로 알려 주세요.

  3. 초대 메일 수락

    가을이 초대를 보내면 Expo에서 메일이 와요. 메일 안의 Accept를 누르면 끝!

    메일이 안 보이면 스팸함도 확인해 주세요.

초대를 수락했다면

  1. 멍냥동네 열기

    이 페이지를 아이폰에서 열고 아래 버튼을 눌러요. Expo Go가 열리면서 멍냥동네가 떠요.

    멍냥동네 열기

    다음부터는 Expo Go를 열면 첫 화면에 멍냥동네가 있어요.

  2. 멍냥동네 회원가입

    앱에서 가입할 때 초대 코드를 넣어요. 코드는 가을에게 받아요.

설치는 한 번만

  1. 앱 설치하기

    아래 버튼을 누르고 Install을 눌러 파일을 받아요.

    멍냥동네 설치하기

  2. 설치 허용

    받은 파일을 열면 "출처를 알 수 없는 앱" 안내가 나와요. 설정 → 허용을 누르고 설치하면 돼요.

    앱스토어 밖에서 받는 앱이라 나오는 안내예요. 처음 한 번만 하면 돼요.

  3. 멍냥동네 회원가입

    홈 화면의 멍냥동네 아이콘을 열고, 가입할 때 초대 코드를 넣어요. 코드는 가을에게 받아요.

가입할 때 이렇게 넣어 주세요

지금은 테스트 기간이라 진짜 인증을 하지 않아요. 실제 개인정보는 넣지 마세요.

• 본인인증: mock-ok- 뒤에 아무 영어 (예: mock-ok-minji)

• 반려동물 등록번호: 1로 시작하는 숫자 15자리 아무거나 (예: 100000000000001)

이럴 땐 이렇게

"is not viewable in Expo Go" 오류가 나와요
아직 초대를 수락하지 않았거나, Expo Go에 다른 계정으로 로그인돼 있어요. 초대 메일의 Accept를 누르고, Expo Go 오른쪽 아래 프로필에서 같은 이메일로 로그인했는지 확인해 주세요.

새 버전이 안 보여요
앱을 완전히 껐다가(위로 쓸어 올리기) 다시 열어 주세요.

그 밖에 이상한 점
화면을 캡처해서 가을에게 보내 주시면 고칠게요. 🙏
